# awesome-repos

A growing catalogue of GitHub repos I've downloaded and explored (mostly [gpui](https://www.gpui.rs/) projects, but all kinds). Each entry has an agent-written evaluation (**good / ok / slop**, with evidence) and an interactive architecture map: a single self-contained HTML file plus the module-flow JSON behind it.

Entries are produced by the `repo-mapper` skill. One folder per repo, named `<owner>__<repo>`.
